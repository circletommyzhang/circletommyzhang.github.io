OpenClaw出现后,90%的猎头都在危险区

2026-02-07 AI/工具/效率 猎头AI 0 评论

一、最近国外一个 OpenClaw 出圈了，它到底是什么？

最近一段时间，在海外技术圈、AI Agent 圈里，一个名字被反复提起：OpenClaw。不是一个聊天机器人，而是一个开源的 AI Agent（智能体）框架。

OpenClaw 最初由奥地利软件工程师彼得·斯坦伯格（Peter Steinberger）开发，它最早在 2025 年 11 月以 Clawdbot 的名字发布在 GitHub 上。后来因为商标问题一度更名为 Moltbot，最终定名 OpenClaw。

OpenClaw 上线后在 GitHub 上增长极快，仅几周就获得了 超过十万颗星（100,000+ stars），这是开源项目中极为罕见的爆发式增长。

它的核心理念很简单：

AI 不只是回答问题，而是可以被授权，去“真的做事”。

也正因为这个定位，它在海外被大量拿来做：

  • 自动化工作流
  • 个人 AI 助理
  • 企业内部 Agent
  • Research / Ops / 投研 / 招聘 等高信息密度岗位的辅助系统

这2天美团联合创始人王慧文也在积极行动，貌似看到的确定性：

敏锐的人应该会思考：他是否可以应用到猎头领域，答案是肯定的

二、对猎头顾问来说，OpenClaw 能做什么？

先说结论：

OpenClaw 不是“替代猎头”，而是会替代大量“猎头每天在做，但并不真正值钱的环节”。

我随便说一些他可以做的环节(技术还在不断演进)

1、网上找人

  • 按目标公司 + 关键词在招聘网站自动搜寻候选人
  • 定时扫描 LinkedIn / 脉脉 / GitHub / Scholar 新增或变动人选
  • 扫描候选人最近动态（发帖、项目、论文、开源更新）
  • 对搜到的候选人进行第一层匹配筛选
  • 将初筛后候选人加入待整理候选池

2、管理人才库（整理 / 打标签 / 结构化）

  • 将候选人登记进表格或系统
  • 拆解候选人简历关键信息
  • 标记候选人技术 / 岗位细分方向
  • 标记候选人职级与角色定位
  • 标记候选人管理团队人数
  • 标记候选人参与项目规模与复杂度
  • 记录候选人过往公司与行业背景
  • 记录与候选人历史联系与沟通要点
  • 将零散文字信息转为结构化字段
  • 合并同一候选人的多来源信息
  • 按技术方向 / 行业 / 职级对候选人分类存储

3、联系他们（开场文案 / 发送）

  • 根据候选人简历生成个性化开场文案
  • 匹配当前岗位生成定向开场文案
  • 自动提取候选人邮箱或允许的联系方式
  • 将开场文案生成至邮件草稿(你自己优化了发送)
  • 在规则约束与充分训练后支持自动发送
  • 记录每一次联系行为与结果

当然，他才刚出现，很多还不是很成熟，但是这是趋势，就像3年前出现ChatGpt一样

  • 部署和配置门槛仍然偏高
  • 对使用者的“流程设计能力”要求高
  • 对权限、安全、稳定性仍需控制

三、哪些是他长期都不能做的？

下面这些，是猎头这份工作的“护城河”。

1、人与人之间的信任

  • 建立真实信任
  • 让候选人说真话
  • 用个人信誉兜底
  • 长期关系维护

2、深层动机与情绪判断

  • 识别口是心非
  • 感知犹豫、焦虑、抗拒
  • 挖掘动机/痛点
  • 理解矛盾心理

3、关键决策与取舍

  • 该不该继续推进
  • 什么时候该停
  • 是否值得消耗关系

4、复杂博弈与影响

  • 非理性行为处理
  • 临场谈判调整
  • 改变一个人的认知

5、责任与后果

  • 为推荐结果负责
  • 为失败关系兜底
  • 在灰度地带做判断
