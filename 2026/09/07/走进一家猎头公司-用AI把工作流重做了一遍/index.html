走进一家猎头公司,用AI把工作流重做了一遍

2026-09-07 AI/工具/效率 猎头AI 0 评论

上周末，带着我的猎头Know-how和各种猎头skill进入了博思人才(一家超百人的猎头公司)。目标非常明确：紧扣真实的猎头业务，把 AI 深度嵌入到他们的工作流中。

首先想厘清一个概念：我所说的“AI 嵌入猎头工作流”，绝对不是教大家怎么用Agent，这太浮于表面；也不仅仅是市面上常讲的“Agent找简历、匹配简历、写推荐报告或寻访话术”。这些当然是各种应用场景，但它们只是孤立的点。

我理解的 AI 嵌入猎头工作流，是重构一家猎头公司：重新审视人、Agent、知识、数据与业务流程的连接方式。最终改变的不是某一个环节的效率，而是整个猎头业务的运转形态。

一、AI 嵌入猎头工作流，必须是一把手工程

谈这两天做了什么之前，我想先提到博思人才的创始人滕总。滕总50多岁，但对 AI 的敏锐度和认知很高。在公司尚未推广 Agent 之前，他就已经主动报名了其他课程、深入研究 AI。

这次培训之后我更加坚信：AI 嵌入工作流，必须是一把手工程。逻辑非常简单：如果只是顾问个人用 AI 写话术、查公司、匹配简历，那是个人提效，不需要老板干预。但若要将 AI 深度融入组织工作流，就会直接触及底层架构：

知识沉淀：公司的知识沉淀在何处？优秀顾问的方法论如何萃取？

数据结构：公司的人才数据如何组织？员工之间如何高效协同？

资产界定：哪些是顾问个人资产，哪些必须转化为公司的公共数字资产？

机制运维：Agent 应该接入哪些业务环节？公司的 Skill 由谁统一维护？

管理管控：业务负责人如何进行质量抽检？新旧工作方式如何无缝切换？

这些问题超越了单个员工的决策范畴，直接关乎业务流程、数据资产与管理模式。如果管理者仅仅口头鼓励“拥抱 AI”却不深度介入，这件事绝难落地。一把手必须先相信、先理解、先参与，才能推动整个组织的变革。

二、第一天：不急于自动化，先搭建系统骨架

第一天上午，我们与管理层展开深度共创。我展示了事先设计的“AI 嵌入猎头工作流”整体框架，并结合博思百人团队的真实业务逐一拆解讨论：

哪些功能是核心刚需？哪些可以阶段性舍弃？

还缺少哪些关键链路？现有 ATS/CRM 系统如何衔接？(ps:谷露已经开放了接口：cli.gllue.com)

全新的 AI 工作方式应该从哪个业务点切入试点？

我们讨论的并非某款具体的 AI 工具，而是一家猎头公司未来所需的 AI 基础设施。

我们把过去散落各处的核心要素重新梳理并整合到一张图谱中：包括公司研究、人才数据、职位信息、Mapping、方法论、实战案例、标准问答、会议纪要、培训资料及业务经营数据。

这些要素过去一直存在，但极度碎片化地散落在不同的顾问头脑中、个人电脑里、文档和独立系统中。AI 带来的核心价值，在于第一次让这些碎片化资产实现了真正贯通。

当公司完成数据与知识的沉淀，Agent 便能在底层持续读取、加工、补充和调用，员工再通过各自的 Agent 高效完成业务交付。我们探讨的根本不是“AI 能否帮我做一件事”，而是“猎头公司的 AI 数字底座应该如何构建”。

三、第一天下午：重构认知，让全员真正理解 Agent

我们集中梳理了几个底层概念(知道了才能举一反三)：什么是 Agent、什么是 Skill/脚本/插件、什么是知识库、什么是GUI/API/CLI/MCP，以及哪些场景适合 AI、哪些环节绝不能为了自动化而自动化。

后一点尤为关键：AI 嵌入工作流，不等于盲目追求全盘自动化。 招聘平台存在严格的风控与数据边界，企业客户也有严苛的保密要求。真正优秀的工作流，是在效率、稳定性与安全性三者之间找到最佳平衡点。

原理之后，每个人都用我的skill跑了一个小流程，真实的感受一下

四、第二天：进入真实业务场景打通链路

第二天抛弃所有概念讲解，直接进入真实业务跑通闭环。我们挑选真实的行业公司、真实的人才线索、真实的在招聘项目，将第一天搭建的骨架跑一遍。

我们沿着猎头全业务链条，将 AI 深度嵌套至各个节点：

业务交付主线：行业与公司研究 → JD 深度解读 → 岗位对焦 → 人才获取 → 信息补全 → 人才结构化标签 → 沉淀人才库 → 深度 Mapping → 人岗精准匹配 → 候选人触达 → 持续跟进。

组织知识主线：业务会议 → 案例萃取 → 方法论提炼 → 标准问答库 → 内部培训 → 公司统一知识库。

管理决策主线：项目实时数据 → 员工过程数据 → 公司经营数据 → 智能数据看板。

我们不是孤立地做一个“AI 找人”的小场景，而是沿着猎头业务的全生命周期+我的各种skill都走一遍

五、核心收获：厘清整体骨架，形成系统认知

第二天结束时，最核心的收获是整个系统的骨架彻底清晰了：

哪些知识必须纳入公司统一知识库；

哪些数据需要长期沉淀与复用；

哪些繁琐工作可以全权交给 Agent 执行；

哪些实战经验需要萃取封装成标准 Skill；

哪些基础设施应由公司统一建设，避免百人团队重复造轮子；

哪些核心环节必须坚守由顾问完成（如深度判断、情感沟通与信任建立）。

过去大家看到的 AI 是碎片化的点：点状的找人工具、匹配工具、话术生成工具。而现在，这些点被串联成一张完整的业务全景图。

六、未来演进：沿着骨架持续丰富业务血肉

两天的实操不可能完成一家百人猎头公司的全盘 AI 改造，这本就不是短时间内能一蹴而就的事情。这两天真正完成的，是把骨架搭建出来，把关键链路跑通一遍，把发展方向与标准彻底确定。

接下来的推进路径非常清晰与扎实：

深入研究一家家目标公司；

持续沉淀一位位候选人信息；

不断完善一张张深度 Mapping 各种图谱；

将每一次业务会议与复盘打卡沉淀进知识库；

留存每一个成单与掉单的真实案例；

在真实业务迭代中反复修正每一个 Skill；

顾问在日常使用中不断发现问题、纠偏优化。

随着数据与知识的持续积累，Skill 会日益成熟，Agent 也会越来越理解这家公司的作业习惯与猎头逻辑。
