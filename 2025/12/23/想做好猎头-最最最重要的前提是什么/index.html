想做好猎头，最最最重要的前提是什么？

2025-12-23 认知/思维/驱动力 猎头认知 0 评论

近半年我写过很多猎头的实操干货。比如这篇猎头实战全集｜72篇实操干货打通全流程。从 BD、找人、首通电话、动机挖掘、候选人维护、客户判断、Offer 谈判……

技能层面，我几乎把我知道的都拆过一遍。这些技能都非常重要。

但是你必须要有一个前提，如果这个前提没有做到，你就会：看起来很专业，但结果出不来。昨天我和wendy的音频访谈中，Wendy的状态再次证明了这一点。没听过这个音频访谈的可以再听一下：音频访谈｜对话"千炳烛"猎头创始人Wendy

一、这个“前提”是什么？

大家都用一个很口语的词来形容它，叫「要性」。

如果换成一个更科学、更专业的说法，我会用：

行动导向型成就驱动（Action-Oriented Achievement Drive）

说人话就是：

在没有人逼、没有即时回报、事情已经不好看了的情况下，

你还会不会继续推进。是一种稳定、可重复的行为倾向。

二、为什么它是“前提”，而不是“加分项”？

因为猎头这个行业，有一个非常残酷的现实：

如果你技能很好，但如果你不行动，就会：

  • 不推进
  • 不追
  • 不逼
  • 不顶
  • 不在关键节点多走那一步

所有技能都会失效。

现实中有一类人是这样的：

  • 技能不错
  • 逻辑清楚
  • 话术完整
  • 有方法论

前一段时间，看起来还可以。

甚至：

  • 中上水平
  • 被时代红利推过一段
  • 在某个好行情里“出过成绩”

但一旦进入：

  • 行情变差
  • 成交周期拉长
  • 客户拖
  • 候选人反复

行动密度下降了。

然后就会出现你我都见过的场景：

“我也很努力啊，只是现在确实比较难。”不是难。是不再往前推了。

三、那是不是“只要有「要性」就行”？

不行，那会变成蛮干。

这是另一头的坑。

只有要性，没有技能，会发生什么？

  • 靠情绪顶
  • 靠冲劲撞
  • 靠主观判断硬来
  • 靠“我觉得可以”去推进

短期可能有结果，

但长期一定会：

  • 误判客户
  • 误伤候选人
  • 反复踩雷
  • 消耗信用

要性不是替代技能，而是让技能生效。

四、要性是天生的吗？能不能被激发？

这是大家问得最多的问题。

一个不太好听、但真实的结论是：

要性不是人人都有，也不可能人人都有。

它不是“目标感强”“上进心”“进取心”的同义词。

那些更多是想法层面的动机。

而要性是，在负反馈条件下：行为是否还能持续推进。

那能不能被训练？

答案是分层的：

  • 从 0 变成 Wendy 那种极强要性，几乎不可能
  • 有一部分人，可以被训练到 “中上等要性”
  • 大多数人，只能靠制度、KPI、团队节奏“暂时托住”(氛围)

换句话说：训练，只能点燃“有可燃物的人”。点不出原本不存在的火。

五、猎头是"销售"还是"咨询"？

这几年有一个老话题反复被讨论：

猎头到底是销售，还是咨询？

如果顺着大家的说法：必须是两者的结合，而且顺序不能反。

如果按我的理解，猎头就是销售，因为我认为的好销售，都具备咨询的能力，只是大部分人对销售是有误解的，这里先不展开

销售，解决的是“要性”，销售型特质意味着：

  • 结果导向
  • 推动力强
  • 敢要
  • 敢逼
  • 敢推进

这是行动层的发动机。

咨询，解决的是“技能”，咨询型能力意味着：

  • 判断更准
  • 分析更深
  • 结构更清晰
  • 决策质量更高

这是让行动不走偏的方向盘。

真正的问题在于：

很多猎头只对“咨询范”感兴趣：

  • 显得专业
  • 显得高级
  • 显得有认知
  • 显得不像“买卖”

但结果往往是：

分析得很专业，事情却推进不了。你如果没有销售型的行动驱动，

咨询能力只会变成：你一个人在那儿想得越来越清楚，但事情没有因此往前走一步。
