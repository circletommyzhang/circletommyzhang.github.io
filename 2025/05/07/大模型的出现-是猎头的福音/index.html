大模型的出现，是猎头的福音

2025-05-07 AI/工具/效率 猎头AI 0 评论

Chatgpt类的产品已经出现2年了，他的出现对于猎头来说，尤其是对专注算法+工程类岗位的猎头来说，大模型的价值远不止“写JD、润色邮件”这么简单

以下是我这2年使用的的总结

一、帮我们“看懂”技术细节，跨越认知边界

做技术猎头最怕什么？怕推荐错方向。

比如一个客户明确需要的是做推荐算法策略的候选人，目标是能在业务线上快速调优策略、提升指标。但你从简历库里找到的一个人，简介写的是“负责推荐系统中的模型优化”。如果不深入分析，你可能会误以为他符合要求，结果实际是他主要做的是推荐模型的预训练优化，属于偏研究型的 offline 基础建模工作，和客户要的策略调参、线上实验、实时 AB 测试完全不是一回事。最后你浪费了很多时间

而现在，你只要把简历贴给 ChatGPT，它会立刻告诉你：

该候选人主攻方向为：大模型算法 → 对齐技术（如DPO） → 推荐系统预训练阶段的结构建模与效率优化

再比如，你看到一个候选人简历里面有几篇顶会论文，每一篇论文很多页，又是英文，很简单，你只要把论文标题发给chatgpt，他可以很清楚告诉你他是做什么技术领域的，如图：

二、帮我们制定“工作节奏策略”

比如，你手上同时要服务 4 个客户，每个客户有 3 个岗位，每个岗位的难度不同，你所拥有的资源也不一样：

  • 有的岗位你已经掌握了候选人电话，可以直接拨打推进；
  • 有的只有邮箱或站内信，需要耐心等待回复；
  • 有的甚至需要通过内部推荐或第三方介绍才能接触到人选。

面对如此复杂的任务排列，如何制定最优策略，把每天的时间分配给最值得推进的任务？

其实，你完全可以把这些信息结构化后交给 ChatGPT，写清楚每个岗位的资源情况、紧急程度、匹配难度，它就能给你一份高效可执行的优先级方案：

哪些先打电话、哪些先建池、哪些岗位要放缓推进节奏……

再结合你的个人判断微调一下，这就是你专属的“猎头工作调度系统”。

三、帮我们“预演谈判”，提升你的影响力

我们在跟进候选人时可能会需要这种场景：

  • “我现在公司很稳，就是觉得成长慢，但换工作太累了。”
  • “我听说xx公司压力大，996的不考虑。”
  • “我做推荐算法的，这种大模型的我能行吗？”

这些都是认知和情绪问题。以前你只有你自己的思路，或者最多问你的同事/老板(还不一定帮到你)，现在你只需要和chatgpt交流，他可以综合各种思路，给你不同的答案

比如：

“一个工作10年的推荐算法工程师，目前在稳定大厂，年包80w，对成长停滞感到焦虑但对跳槽缺乏信心，该如何设计一套逐步引导他转变认知的对话框架？”

GPT 可以根据 MBTI 性格模型、候选人背景、行业趋势给出“多轮沟通脚本”，甚至连你每句话后面“他可能的反应”和“如何继续推进”都能预测。

这就好比你请了一个谈判教练，实时陪你“复盘”对话与反应机制，让你在与技术人沟通时，既专业又心理穿透力更强。

四、未来展望：当 AI agent 成熟，猎头将真正只专注“高阶沟通”

你可以想象一个不远的未来：

  • 你把 JD 和客户需求输入系统；
  • Agent 去各个数据库（领英、脉脉、OpenReview）抓人；
  • 自动解析技术方向、匹配岗位、写定制化邮件；
  • 自动筛选回复并汇总有意向的人选；
  • 你只需要——打那一通最关键的电话，完成最终说服。

这不是幻想。现在已有早期 Agent 原型可以结合 RAG 检索、候选人简历理解、对话生成和多轮交互逻辑链规划。只要技术继续演化，你的猎头助手就能替你完成 30%的“信息工作”。

你，只需要发挥那70%的判断力、谈判力、人性洞察力。

总结

所有以咨询为核心、没有实体产品的工作，随着大模型的发展，正迎来前所未有的助力。但前提是：你必须真正学会如何使用它，才能显著提升效率与产出。
