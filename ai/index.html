人才录入 Skill｜高级版

JD 录入 Skill

帮你把招聘网页、文档、PDF、图片或你发来的 JD 录入飞书多维表格，给岗位打上与人才库一致的标签，例如“算法 → 大模型算法 → 预训练”。再用白话拆解岗位，讲清楚实际做什么、需要什么能力，让人一看就懂。

人才触达 Skill

根据你的 JD，从人才库找出匹配的人才，结合每个人的简历写有针对性的文案(加好友、发私信、发邮件），针对性非常重要

公司研究 Skill

从业务、市场、团队、增长、竞争和风险等11个维度研究任何你要挖猎的公司，帮助你了解你的目标公司。

项目拆解 Skill

结合你合作的公司和 JD，帮你深刻理解：你服务的公司的情况、岗位在组织中的位置及画像、应该去哪里挖人

推荐报告生成skill

把候选人的简历和你的评语等信息给你的agent,他会按你自己的模板整理成推荐报告。也可以在你同意后优化简历表达、提炼顾问评价，让候选人的经历和成果更清楚。

辅助 Mapping Skill

通过全网搜索目标公司的公开资料，结合你人才表里的全部信息，帮你画出目标公司的人才 Mapping 和组织图；后续获得的新线索，也会核实后持续补进去。

知识库框架搭建 Skill

将以上所有内容和你做单时的所有信息统一整理到一个结构清晰的知识库中，方便管理和持续沉淀各家公司的资料，也让 Agent 和你能快速找到所需信息，开展猎头工作。
